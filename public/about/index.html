Anomalradio.com

A single station that plays only its own music, around the clock, from its own library. No label feed, no licensed catalogue, no third-party player.

What you are listening to

The rotation is built from the station's own releases — currently the catalogue — and loops in album order, with per-track weighting controls planned for the admin panel.

Two listening modes

  • Live — you join mid-track and the station moves on without you. No seeking, like broadcast radio.
  • On demand — you pick a track, it plays from the start and the queue continues through the library.

Both modes run through the same protected endpoint, and neither exposes a downloadable file URL.

Stream protection — the honest version

Anything a browser can play, a determined person can record. No client-side trick changes that, and anyone promising “100% undownloadable” is selling something false. What this station actually does:

  • Storage isolation — audio lives outside the web root (or in a private bucket) and is never served as a file. Requests for .mp3 paths return 404, not 403.
  • Opaque ids — the public world only ever sees ids like ar_Kt0j2bAUde; the mapping to a real file exists only on the server.
  • Short-lived tokens — each stream request needs a signed token that expires in about two minutes and is bound to the requesting IP and browser, so a copied URL is worthless almost immediately.
  • Anti-ripper rules — known rippers and CLI tools are refused, requests without a browser context are refused, and per-IP concurrency is capped.
  • Continuous stream (next milestone) — in live mode the listener will receive one endless mount and no per-track resource at all, which is the strongest practical protection.
  • Watermarked purchases — files bought from the shop carry an order watermark, so leaks can be traced back.

Hard DRM (Widevine/FairPlay) is deliberately not used: it requires a licence server, breaks some browsers, and costs more than it protects for a station of this size.

Terms of use

  • Listening is free; the music stays the property of its authors.
  • Recording, ripping, redistributing or re-uploading the stream is not permitted.
  • Do not hotlink, embed or proxy the audio endpoints on other sites; use the player or the embed widget.
  • Favourites and baskets are stored in your browser; no account is required.

Privacy

  • No third-party analytics, no ad trackers, no fingerprinting, no external font or script CDNs.
  • One functional cookie stores an anonymous owner key for your favourites and basket.
  • Stream requests are logged with hashed IP and User-Agent purely for abuse protection.
  • Payments (when the shop opens) are handled by the payment provider; card data never touches this server.

Where this runs

The station is two different things, and it is worth being clear about which one you are looking at:

  • The site — pages, catalogue, per-track pages, favourites, basket. Static files. These work anywhere, including the file-only host that currently answers for anomalradio.com.
  • The station — the token-gated stream, the database, the private audio storage, the scheduler. This needs a Node process with a writable disk, which a file host cannot provide.

Right now this domain is served as a static snapshot: the catalogue and the pages are real, and playback is not available yet. When the snapshot is published you will see a “static preview” note at the top of every page.

The machine in the DNS record (81.2.196.19) is shared hosting — no shell, no long-running processes — so the station needs its own host: a small VPS running Node behind nginx with TLS, as described in the deployment plan. Until then this domain stays an honest preview rather than a player that cannot play.
